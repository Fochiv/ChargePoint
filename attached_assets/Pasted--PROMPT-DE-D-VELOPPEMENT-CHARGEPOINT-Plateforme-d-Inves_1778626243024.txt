🎯 CONTEXTE GÉNÉRAL DU PROJET
Tu es un développeur full-stack senior. Tu dois concevoir et développer une plateforme d'investissement en ligne nommée ChargePoint, inspirée du secteur des bornes de recharge pour véhicules électriques. La plateforme permet à des utilisateurs du monde entier d'investir selon des plans VIP prédéfinis, de percevoir des revenus journaliers, et de bénéficier d'un système de parrainage multi-niveaux. Elle intègre un système de paiement automatique via l'API Ashtechpay, prenant en charge tous les pays disponibles dans cette API. Le site sera accesible via :  https://chargepoint.zya.me

COMPORTEMENT CRITIQUE — SUIVI EN TEMPS RÉEL DU STATUT DE PAIEMENT
Après validation du formulaire et initiation du paiement via l'API Ashtechpay :
Étape 1 — Initiation :
•	Appel à l'API Ashtechpay pour créer la transaction
•	L'API retourne un transaction_id et le statut initial "pending"
•	Enregistrer la transaction en base de données avec statut "pending"
Étape 2 — Écran de suivi (affiché immédiatement) :
•	Afficher un écran dédié (overlay ou page) avec : 
o	Message : "Veuillez valider le paiement sur votre téléphone"
o	Compteur dégressif 08:00 → 00:00 (8 minutes)
o	Indicateur de chargement animé (spinner ou pulse)
o	Montant , Numéro de téléphone qui va valider la transaction + méthode de paiement rappelés
o	Statut en temps réel : 🟡 En attente... → 🟢 Validé / 🔴 Échoué
Étape 3 — Polling automatique :
// Pseudo-code du mécanisme de polling
const pollPaymentStatus = async (transactionId) => {
  const interval = setInterval(async () => {
    const response = await fetch(`/api/payment/status/${transactionId}`);
    const { status } = await response.json();

    if (status === "success") {
      clearInterval(interval);
      clearTimeout(timeoutTimer);
      await updateTransactionInDB(transactionId, "success");
      await creditUserAccount(userId, amount);
      await activateInvestmentPlan(userId, planId); // si applicable
      redirectTo("/dashboard?deposit=success");
    }

    if (status === "failed") {
      clearInterval(interval);
      clearTimeout(timeoutTimer);
      await updateTransactionInDB(transactionId, "failed");
      showError("Le paiement a échoué. Veuillez réessayer.");
    }
  }, 3000); // Polling toutes les 3 secondes

  // Timer de 8 minutes (timeout)
  const timeoutTimer = setTimeout(async () => {
    clearInterval(interval);
    await updateTransactionInDB(transactionId, "expired");
    showError("Délai expiré. Votre transaction n'a pas été confirmée à temps.");
    showRetryButton();
  }, 8 * 60 * 1000); // 8 minutes
};
Étape 4 — Résultats :
•	✅ Succès → Mettre à jour le solde utilisateur + activer le plan VIP si applicable → Rediriger vers le Tableau de bord avec message de succès
•	❌ Échec ou expiration → Afficher message d'erreur clair + bouton "Réessayer" → Permettre relance sans recharger la page

⚙️ LOGIQUE MÉTIER CRITIQUE
Distribution des gains journaliers(gains ajoutes en fonction du VIP)
Tâche CRON : Tous les jours à 00:00 UTC
→ Pour chaque investissement actif (status = "active") :
  1. Ajouter daily_gain au solde de l'utilisateur
  2. Enregistrer une transaction type "daily_gain"
  3. Décrémenter days_remaining
  4. Si days_remaining = 0 → mettre investment.status = "completed"
Calcul des commissions de parrainage (lors d'un dépôt validé)
Lors de deposit.status → "success" :
→ Trouver parrain niveau 1 (user.referred_by) → créditer 20% du montant déposé
→ Trouver parrain niveau 2 (parrain_niveau1.referred_by) → créditer 5%
→ Trouver parrain niveau 3 (parrain_niveau2.referred_by) → créditer 2%
→ Enregistrer chaque commission comme transaction type "referral_commission"
